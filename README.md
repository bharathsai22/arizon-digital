# E-Commerce Frontend with React.js and Tailwind CSS

A fully functional e-commerce frontend built with React.js, Tailwind CSS, and Zustand for state management.

## Features

- Product listing page with API integration
- Shopping cart functionality
- Mini cart dropdown
- Responsive design
- Product search and filtering (optional)
- Checkout process (simplified)
